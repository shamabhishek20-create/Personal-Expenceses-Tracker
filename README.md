# Personal Expense Tracker Web Application

## 📌 Project Overview
The Personal Expense Tracker is a web-based application that helps users record, manage, and monitor their daily expenses. It provides a simple dashboard to understand spending habits and track monthly expenses.

## 🎯 Objectives
- To record daily expenses easily.
- To organize expenses by category.
- To calculate monthly spending.
- To search and filter expense records.
- To export expense records as a CSV file.

## ✨ Features
- Add, edit, and delete expenses.
- Categorize expenses such as Food, Travel, Shopping, Education, and Bills.
- View monthly expense summaries.
- Visualize spending using a category-wise chart.
- Filter expenses by month and category.
- Search expense descriptions.
- Export expenses to CSV format.
- Save expense data in the browser using Local Storage.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used
- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application functionality and calculations.
- **Chart.js** – Expense visualization.
- **Local Storage** – Saving data in the browser.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your expenses.

You can also use the **Live Server** extension in Visual Studio Code to run the website.

## 💾 Data Storage
The application uses browser Local Storage to save expense records. The data remains in the same browser on the same device unless the browser data is cleared. The current version does not use a server or cloud database.
